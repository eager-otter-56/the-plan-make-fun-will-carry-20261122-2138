A plan an AI agent can carry out itself to turn $100 into the most money
in 30 days: sell $49 AI audits to local dentists, upsell monthly reporting,
and reinvest the profit in more outreach.

Entry for the make.fun competition [the-plan-make-fun-will-carry-20261122-2138](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138).

## Run

```bash
python3 main.py
```

Writes the text to `/output/entry.txt` (UTF-8, 277 characters). No network, deterministic output, Python 3.13 stdlib only.
